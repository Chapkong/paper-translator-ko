# 학술 논문 한국어 번역 규칙 (academic-korean)

목표: 원문의 논리와 정보량을 100% 보존하면서, 한국 학술지 논문에 실려도 어색하지 않은 한국어를 쓴다.
"정확하지만 번역투인 문장"과 "자연스럽지만 정보가 빠진 문장" 둘 다 실패다.

## 1. 완역 원칙 (구조 보존)

- 문단 1:1 대응. 문단을 합치거나 나누지 않는다. 문장은 한국어 흐름상 필요하면 합치거나 나눌 수 있다.
- 요약·생략·의역 금지. 반복되거나 사소해 보이는 문장도 모두 옮긴다.
- Markdown 구조(`#` 헤딩 수·레벨, 표 행 수, 리스트, 강조, 각주 표기)는 원문과 동일하게 유지한다.
- `![](images/...)` 이미지 링크 줄은 **한 글자도 바꾸지 말고 그대로 복사**한다. 그림 캡션(Figure 1. …)은 번역한다: `그림 1. …`, 표 캡션은 `표 1. …`.
- 수식·변수·기호(S_eff, l_k, $...$, 코드 블록)는 원문 그대로. 수식 앞뒤 설명문만 번역한다.
- 인용 표기 `(Berryman, 1983)`, `(Cannady et al., 2014)`는 원문 그대로 둔다. 본문에 저자명이 주어로 나오면 `Berryman(1983)은 …` 형식.
- References/참고문헌 섹션은 번역하지 않고 원문 그대로 둔다 (헤딩만 `참고문헌`으로).
- 저자명·기관명·고유명사는 원어 유지. 널리 쓰이는 한국어 명칭이 있는 기관(OECD, 세계은행 등)만 한국어 표기.

## 2. 문체 (학술 서술체)

- 종결: `~다`, `~이다`, `~하였다/했다`, `~한다`. 논문의 시제를 따른다 (선행연구 서술은 과거, 일반 명제·본 연구 주장은 현재).
- 격식: `~습니다` 금지, 구어체 금지, 개조식(명사형 종결) 금지 — 이 스킬은 **서술체 완역용**이다. 개조식 요약이 필요하면 별도 스킬(gaejosik-writing)을 쓴다.
- 1인칭 `We`는 `본 연구는`, `우리는`(연속 등장 시 생략) 또는 무주어 피동으로 처리. `This paper`는 `본 논문은`.
- 문장 길이: 원문이 60단어 넘는 문장이면 두 문장으로 나눈다. 한국어 한 문장 = 최대 2개 절 권장.

## 3. 번역투 제거 규칙 (자주 나오는 패턴)

| 영어 패턴 | 피할 번역투 | 권장 |
|---|---|---|
| passive `X is defined as` | X는 ~로 정의되어진다 | X는 ~로 정의된다 / ~로 정의한다 |
| `It is important to note that` | ~라는 것에 주목하는 것이 중요하다 | 주목할 점은 ~이다 / 특히 ~ |
| `suggest that / indicate that` | ~라는 것을 제안한다 | ~임을 시사한다 / ~을 보여준다 |
| `in terms of` | ~의 관점에서 | ~ 측면에서 / ~에서 |
| `have an effect on` | ~에 영향을 가진다 | ~에 영향을 미친다 |
| `whether or not` | ~인지 아닌지 여부 | ~인지 (여부) |
| `-s` 복수 | 연구자들, 정책들 | 문맥상 불필요하면 `들` 제거 |
| `a/an`, `the` | 하나의, 그 | 원칙적으로 번역하지 않음 |
| `X and Y respectively` | 각각 X와 Y | X와 Y가 각각 |
| `not only A but also B` | A뿐만이 아니라 B도 또한 | A뿐 아니라 B도 |
| `it can be seen that` | ~라는 것이 보여질 수 있다 | ~임을 알 수 있다 |
| `however, moreover, therefore` 문두 남발 | 그러나, 더욱이, 그러므로 매 문장 | 접속사 절반은 생략하거나 어미로 흡수 |
| 명사구 나열 (`the estimation of the effect of X on Y`) | X가 Y에 미치는 영향의 추정 | X가 Y에 미치는 영향 추정 / X가 Y에 미치는 영향을 추정하는 것 |
| 관계절 `which/that ... ` 장문 | ~인 ~인 ~인 (수식 3중첩) | 문장을 끊고 `이는 ~`로 이어 받기 |
| `according to` | ~에 따르면 (남발) | ~에서는 / ~은 ~라고 본다 |

- 조사 생략 금지: "연구자 수 감소 추세 확인"처럼 조사 없는 전보문 금지 (개조식 아님).
- 같은 명사 반복은 대명사 대신 그대로 반복해도 좋다(한국어는 지시대명사 남용이 더 어색).
- 숫자·단위: 아라비아 숫자 유지, `27%` → `27%`, `48,213` 유지, `2018 to 2022` → `2018~2022년`.

## 4. 용어 일관성

- 번역 시작 전 `glossary.md`(용어 대응표)가 있으면 반드시 그 대응을 따른다. 없으면 첫 등장에서 `한국어 역어(English term)` 병기 후 이후 한국어만 쓴다.
- 학계 관행 역어 우선: effective supply → 유효공급, leaky pipeline → 누수 파이프라인, leakage → 누수, attrition → 이탈, hazard model → 위험모형, panel → 패널, cohort → 코호트, underemployment → 하향취업, emigration → 해외이주, retention → 잔류, early-career → 초기경력.
- 역어는 **하나만** 고른다. `해외이주(유출)(emigration)`처럼 대안 역어를 괄호로 덧붙여 괄호가 중첩되는 표기 금지. 병기는 `한국어(English)` 한 쌍만, 첫 등장에서만.
- 원문에서 이탤릭/따옴표로 강조된 신조어(`'porous pipeline'`)는 `'다공성 파이프라인(porous pipeline)'`처럼 병기.

## 5. 검수 체크리스트 (reviewer용)

1. 원문 문단 수 = 번역 문단 수인가? 빠진 문장이 있는가? (가장 중요 — 문장 단위로 대조)
2. 숫자·통계값·연도·기호가 원문과 하나도 다르지 않은가?
3. 이미지 링크·수식·인용 표기가 원문 그대로인가?
4. 3절의 번역투 패턴이 남아 있는가? 한 문단에 2개 이상이면 재작성 요구.
5. 용어가 glossary와 일치하고 문서 전체에서 하나로 통일되었는가?
6. 종결 어미가 학술 서술체(~다)로 일관되는가? `~습니다`, 명사형 종결 혼입 없음?
7. 소리 내어 읽었을 때 한국어 논문처럼 읽히는가? 원문을 모르는 독자가 이해할 수 있는가?

검수 결과는 `PASS` 또는 `REVISE` + 문제 문장 원문/번역/수정안 목록으로 보고한다.
